C-Teacher 交互规范展示

基于全局交互规范生成的具体页面示例，展示各组件的标准用法

1. 页面顶部操作栏

标题在左侧，操作按钮在右侧，使用 n-space 排列

课堂记录

管理学生的课堂表现和作业情况

<div class="page-top"> <div> <h1 class="page-title">课堂记录</h1> <p class="page-subtitle">管理学生的课堂表现和作业情况</p> </div> <n-space> <n-button>选择文件</n-button> <n-button type="primary"> <template #icon><Plus :size="16" /></template> 新建记录 </n-button> </n-space> </div>

2. 按钮类型

primary（主要）、secondary（次要）、error（危险）、quaternary（轻量）

<!-- 主要按钮 --> <n-button type="primary">主要操作</n-button> <!-- 次要按钮 --> <n-button secondary>次要操作</n-button> <!-- 危险按钮 --> <n-button secondary type="error">删除</n-button> <!-- 小号按钮 --> <n-button size="small" secondary>编辑</n-button> <!-- 微号按钮 --> <n-button size="tiny" secondary type="error">删除</n-button>

3. 返回按钮

secondary 样式 + ArrowLeft 图标 + 目标页面名称

<n-button secondary @click="goBack"> <template #icon><ArrowLeft :size="16" /></template> 返回小孩列表 </n-button>

4. 列表行操作

编辑（secondary）在前，删除（error）在后

陈
陈一诺

小学三年级 · 数学、语文

李
李明轩

小学二年级 · 英语、科学

<div class="list-row"> <div class="list-row-left">...内容...</div> <n-space size="small"> <n-button size="small" secondary>编辑</n-button> <n-button size="small" secondary type="error">删除</n-button> </n-space> </div>

5. 空状态

当列表为空时显示，引导用户操作

暂无课堂记录

点击上方"新建记录"开始添加

<div class="empty-state"> <n-icon size="48" color="#ccc">...图标...</n-icon> <p>暂无课堂记录</p> <p class="empty-hint">点击上方"新建记录"开始添加</p> </div>

6. 标签 Tag

用于分类、状态等轻量标记

数学 语文 英语 已完成 待批改
<span class="group-tag">数学</span> <span class="group-tag">语文</span>

7. 表单弹窗

n-modal preset="card"，表单标签 top 对齐，底部右对齐按钮

<n-modal v-model:show="showModal" preset="card" :title="modalTitle"> <n-form label-placement="top"> <n-form-item label="小孩姓名"> <n-input v-model:value="form.name" placeholder="例如：陈一诺" /> </n-form-item> </n-form> <template #footer> <n-space justify="end"> <n-button @click="showModal = false">取消</n-button> <n-button type="primary" @click="save">保存</n-button> </n-space> </template> </n-modal>

8. 页面内联表单

用于新建/编辑页面，顶部返回按钮 + 底部操作按钮

新建课程

填写课程信息

<template v-else> <div class="page-top"> <div> <h1 class="page-title">新建课程</h1> </div> <n-button secondary @click="goBack"> <template #icon><ArrowLeft :size="16" /></template> 返回课程表 </n-button> </div> <section class="side-panel schedule-form-page"> <n-form label-placement="top"> <!-- 表单字段 --> </n-form> <n-space> <n-button type="primary">创建课程</n-button> <n-button secondary @click="goBack">取消</n-button> </n-space> </section> </template>

10. 消息提示

使用 useMessage()，支持 success / warning / error / info

import { useMessage } from "naive-ui"; const message = useMessage(); message.success("资料已保存"); message.warning("请填写资料名称"); message.error("打开资料失败");
